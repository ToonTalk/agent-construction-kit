The Making of Agent Kit

Agent Kit is a glass-box construction kit in which young people build societies of AI agents and small programs, and watch every message between them. Claude Code built it with Ken Kahn in one long session, from 30 September to 3 October 2026. This is how.

Where it came from

Agent Kit grew out of several of Ken's earlier apps, each of which explored part of the idea:

  • the Atelier, a meta-constructionist app in which children build societies of minds;
  • the Agentic AI Explorer, whose agents passed messages by rules;
  • the Logo Evolution Lab, which evolved turtle drawings with AI critics;
  • the PB&J Algorithm Sandbox, from Acquiring computational thinking skills together with a chatbot.

Before any code, Ken held a simulated panel in a claude.ai chat, with the voices of Seymour Papert, Marvin Minsky, Lev Vygotsky and Alan Kay. They discussed these apps and agreed on a design: a kit with microworlds shipped inside it, programmed agents written as pseudocode but translated once into deterministic JavaScript (“a stable bug is a gift; a stochastic bug is a ghost”), and a glass box throughout. The chat produced a specification, which Claude Code then built from.

How it was built

Every change went around the same loop:

Ken tries it→a prompt, often with a screenshot or a tester's report→a patch script→the test suite→screenshots in headless Chrome→commit and push→wait until GitHub Pages serves it
  • Patches were scripts, not hand edits. Each change was a small Python script of exact replacements, and each replacement asserted that its anchor appeared exactly once. A change aimed at the wrong spot failed loudly instead of landing quietly.
  • Tests ran the real page in jsdom, including whole runs of every microworld with scripted stand-in models. The suite grew from 213 tests to 520. Several bugs were found only because a new test failed: an emoji whose invisible joiner was stripped on saving, and a board that wasn't drawn before it was your turn.
  • Claude Code checked its own screenshots. A headless Chrome script took 91 of them, of new features and of layouts at full size, and the session looked at each before reporting.
  • Reviews from outside. Ken's own testing came first. There were also test runs by Claude in Chrome (some with simulated panels of their own), a review by ChatGPT 6.1 Sol, and a “next changes” document Ken put together from all of them.
  • Memory across the long session. The conversation was compacted three times. A specification with an append-only change log (35 entries), a handoff file and a few memory notes carried the decisions forward.

Decisions that shaped it

  • Glass box, but simple first. Each screen shows a short, simple view by default, and the details open on a click. Drawings are Logo, never JavaScript. Rules read as sentences, with an Edit button for the controls.
  • Programs judge, models perceive. A model only suggests; a program anyone can read decides, as the Referee does in Tic-Tac-Toe and the Ledger does in Trail Mix Barter.
  • Stop adding microworlds, and test with children. After nine, the reviewers agreed. New ideas became examples under ＋ New society.
  • Settings is for grown-ups. Children choose among the models a teacher has added, without opening Settings.
  • Honest wording. The trace shows what the kit sent and got back, not what a model learned in training.

Making the Swedish copy

To test whether anyone with a coding agent could make Agent Kit in their own language, Claude Code made a Swedish copy the way such an agent would:

  • It wrote a shared glossary, split the file into nine parts at its section markers, and had nine agents translate the parts at the same time, each keeping its line count.
  • While they worked, it passed messages between them about words that one part depends on another part getting exactly right. For example, the learner's name is now “Du”, and the Small Helper's program checks for that name.
  • It joined the parts and checked them with tests that don't depend on the language.

About 25 English sentences were left out of roughly 1,200, all from the scripted stand-ins. The recipe is now TRANSLATING.md.
